# 🏛️ BhoomiSetu — Land Acquisition Early Warning System (EWS)
**Smart India Hackathon 2026 | Problem Statement ID: SIH26016**

A production-grade AI intelligence system that predicts infrastructure project delay risk 90 days in advance using regularized 500-Tree XGBoost and TreeSHAP explainability, grounded in the RFCTLARR Act (2013).

### Key Highlights
- **ROC-AUC:** 0.9738 | **Accuracy:** 91.37% | **Recall:** 93.94%
- **Explainability:** Exact local TreeSHAP factor attributions (Aadhaar DBT lag, Court writs, RoW velocity).
- **Counterfactual Simulator:** Real-time administrative intervention testing for District Collectors & Project Directors.
